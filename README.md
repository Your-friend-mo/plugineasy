# PluginEasy

Official directory for verified free mobile app plugins, game enhancements, and signed installer packages for iOS and Android.

## Features
- **Responsive Mobile & Desktop Design**: Fully responsive layout matching modern mobile app stores.
- **Intelligent Search Engine**: Universal search with instant live filtering, 1-letter prefix search, Damerau-Levenshtein typo tolerance, and Unicode diacritic/accent normalization.
- **Content Locker Integration**: Automated device pairing sequence, multi-stage installation progress tracker, direct APK download handler, and fallback offer feed.
- **Complete SEO Suite**: 75 verified pages, strict 30x keyword density on 71 landing & product pages, Question-style H3 headings, benchmark data table, citations, JSON-LD Schema markup, `sitemap.xml`, `robots.txt`, and `llms.txt`.

## Deployment
Hosted on Cloudflare Pages.
